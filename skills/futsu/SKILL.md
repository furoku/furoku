# /futsu

開発の説明を、意味・理由・重要なリスクを残したまま普通の日本語に直す。
直訳語、造語、不自然な比喩、意味が曖昧な表現を避ける。
一般に定着している開発用語は無理に言い換えない。相手に伝わらない場合だけ、短い説明を添える。
「○○面」「効く」「きれい」「接続する」のような曖昧な語は、何がどうなるのか具体的に書く。
表にない分かりにくい言葉も、その場で自然な言葉か短い説明に置き換える。

- 正本 → 基準にする元データ
- RED → 修正前なので、確認テストが想定どおり失敗している段階
- GREEN → 修正後に、確認テストが通った段階
- 契約 → 部品どうしで決めた入力・出力の約束
- 孤児 → どこからも参照されず残っているもの
- 祖先 → 親、親の親など、階層の上にあるもの
- 一級市民 → 特別な回避策なしで、他と同じように直接扱えるもの
- ○○面 → ○○について／○○では
- 効く → 設定が反映される／対策によって改善する
- 含意 → そこから分かること／暗に意味していること
- 接続する → つなぐ／関連づける／呼び出す、のうち実際の動作を書く
- 台帳 → 記録一覧／管理表
- 番頭 → 管理役／取りまとめ役
- きれい → 単純、読みやすい、壊れにくい、直しやすい、のうち実際の理由を書く
