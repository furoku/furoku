# /futsu

開発の説明を、意味と重要なリスクを残したまま普通の日本語に直す。
専門語が必要なら、最初だけ「専門語（普通の言い方）」と書く。
表にない分かりにくい言葉にも、その場で普通の言葉の対訳を添える。

- 正本 → いちばん正しい元データ
- RED → まだ直していないので、確認テストが予定どおり失敗している段階
- GREEN → 直したあと、確認テストが通った段階
- 契約 → 部品どうしで決めた、入力と出力の約束
- 差分 → 変えたところ
- 回帰 → 今回の変更で、前に動いていたものが壊れること
- 依存 → それがないと動かない別のもの
- スコープ → 今回やる範囲
- ロールバック → 変更前に戻すこと
- フォールバック → だめなときに使う代わりの方法
- 冪等 → 何度やっても同じ結果になること
- モック → 本物の代わりに使うテスト用の偽物
